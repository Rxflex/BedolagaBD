| Термин | Что это |
|---|---|
| **Remnawave** | Панель управления VPN-инфраструктурой: юзеры, ноды, сквады, профили Xray, лимиты. Ядро всего стека. → [01 Панели](../docs/01-панели/README.md) |
| **Bedolaga** | Telegram-бот-магазин к Remnawave: тарифы, оплаты, промокоды, триалы, рассылки. Он же «бедолага». → [01 Релизы](../docs/01-панели/релизы.md) |
| **Cabinet / кабинет** | Веб-ЛК пользователя (`bedolaga-cabinet`): оплата, устройства, QR, автологин. → [01 Панели](../docs/01-панели/README.md) |
| **Сабка / subscription page** | Страница подписки Remnawave, отдающая конфиг клиенту: `/sub/<token>`. Часто выносят на отдельный домен. → [01 Установка](../docs/01-панели/установка-обновление.md) |
| **Сквад (squad)** | Группа нод в Remnawave, которую видит пользователь как «сервер» или «страну». |
| **Профиль** | Набор Xray-конфигов (инбаунды), который панель раскатывает на ноды. |
| **Хост** | Запись в панели, связывающая сквад/профиль с доменом и портом — то, что попадает в конфиг клиента. |
| **HWID** | Привязка подписки к устройству. Лимит устройств и «сброс HWID» — оттуда. |
| **Промогруппа** | Группа пользователей со своими скидками и периодами в Bedolaga. |
| **Грейс / grace** | Период доступа после истечения подписки (`GRACE_ACCESS_MODE`). При миграции на Remnawave 3.0 включали последним. → [01 Установка](../docs/01-панели/установка-обновление.md) |
| **Решала** | `Reshala-Remnawave-Bedolaga` (DonMatteoVPN) — комбайн обслуживания и защиты панели. → [07 Решала](../docs/07-скрипты/решала-защита.md) |
| **Marzban / 3x-ui** | Панели предыдущего поколения; в базе — миграции с них на Remnawave. → [01 Marzban и 3x-ui](../docs/01-панели/marzban-3x-ui.md) |

</details>

<details open>
<summary><b>Транспорты и Xray</b></summary>

| Термин | Что это |
|---|---|
| **VLESS** | Протокол Xray без собственного шифрования — шифрование берётся из транспорта (Reality/TLS). |
| **Reality** | Маскировка TLS без своего сертификата: нода прикидывается чужим сайтом. Основа 2025-го, к середине 2026 массово выбита ТСПУ. → [02 Reality](../docs/02-транспорты/reality.md) |
| **XHTTP** | Транспорт Xray поверх HTTP; с 11.2025 главный рабочий рецепт в связке с selfsni. → [02 XHTTP](../docs/02-транспорты/xhttp.md) |
| **Selfsteal** | «Воруешь у себя»: Reality смотрит на твой же сайт-заглушку на том же сервере, SNI — твой домен. → [02 Selfsteal](../docs/02-транспорты/selfsteal.md) |
| **Selfsni** | То же про SNI: подставляешь собственный домен вместо чужого популярного. |
| **SNI** | Имя домена в открытой части TLS-рукопожатия. По нему ТСПУ и режет. → [02 SNI и fingerprint](../docs/02-транспорты/sni-fingerprint.md) |
| **Fingerprint / uTLS** | Отпечаток TLS-клиента (`chrome`, `firefox`, `safari`, `randomized`). В 05.2026 начали ловить именно `chrome`. |
| **TLS-in-TLS** | Признак «TLS внутри TLS» — по нему вычисляют прокси даже без SNI. → [03 Детект](../docs/03-обход-тспу/детект-fingerprint.md) |
| **destOverride** | Настройка сниффинга Xray: чем перебить адрес назначения (`http`, `tls`, `quic`). |
| **xver** | Версия PROXY-протокола между Reality и локальным веб-сервером (обычно `1`). |
| **shortIds / privateKey / spiderX** | Параметры Reality: короткие идентификаторы клиентов, приватный ключ, путь-приманка. |
| **Hysteria2** | UDP-транспорт с обфускацией; держался, когда TCP душили. → [02 Hysteria2](../docs/02-транспорты/hysteria2.md) |
| **gRPC / WS** | Транспорты поверх HTTP/2 и WebSocket; резерв и основа для работы через CDN. |
| **SS-2022** | Shadowsocks 2022 (blake3) — чаще всего в роли моста RU→EU. → [02 Shadowsocks](../docs/02-транспорты/shadowsocks.md) |
| **Балансер** | `leastLoad` / `leastPing` в Xray: раскидывает трафик по нескольким аутбаундам. → [02 Балансеры](../docs/02-транспорты/балансеры.md) |
| **finalmask** | Экзотические транспорты августа 2026: маскировка под SSH, DNS, Minecraft/XMC. → [03 Методы обхода](../docs/03-обход-тспу/методы-обхода.md) |

</details>

<details open>
<summary><b>Блокировки: кто и чем режет</b></summary>

| Термин | Что это |
|---|---|
| **ТСПУ** | Технические средства противодействия угрозам — оборудование РКН у операторов, которое и фильтрует. → [03 Обход ТСПУ](../docs/03-обход-тспу/README.md) |
| **ДПИ / DPI** | Глубокая инспекция пакетов: анализ содержимого, а не только адресов. |
| **СКАТ** | Одна из платформ ТСПУ (VAS Experts). В чате — синоним «оборудование, которое отбрасывает Reality». |
| **БС / белые списки** | Подсети, которым ТСПУ разрешает ходить наружу. Дают РФ-облака; то включают, то отбирают. → [03 БС](../docs/03-обход-тспу/бс-подсети.md) · [05 Списки подсетей](../docs/05-хостинги/бс-подсети.md) |
| **Мост / каскад** | Вход на РФ-сервер (в БС-подсети) с выходом через зарубежную ноду. Лечит и блок, и шейпинг. → [03 Мосты](../docs/03-обход-тспу/мосты.md) |
| **CDN-фронтинг** | Трафик идёт через РФ-CDN (Yandex, Beeline/CDNVideo, VK, MWS), потому что CDN не блокируют. Аккаунты массово снесли в 08.2026. → [03 CDN-фронтинг](../docs/03-обход-тспу/cdn-фронтинг.md) |
| **Шейпинг** | Не блок, а принудительное занижение скорости (Сибирь 16.08.2026, Ростелеком до 40 Мбит/с за границу). |
| **WARP / wgcf** | Cloudflare WARP как аутбаунд: обход геоблоков и «чистый» выход. → [03 WARP](../docs/03-обход-тспу/warp.md) |
| **РКН / ГРЧЦ** | Роскомнадзор и его Главный радиочастотный центр — источник предписаний хостерам. |
| **Бан по /32 vs /24** | К 23.08.2026 банят отдельные адреса, а не подсети целиком — дешевле менять IP. |

</details>

<details open>
<summary><b>Инфраструктура и тюнинг</b></summary>

| Термин | Что это |
|---|---|
| **BBR** | Алгоритм контроля перегрузки TCP; первое, что включают на ноде. → [04 sysctl, BBR, MTU](../docs/04-сеть-серверы/sysctl-bbr-mtu.md) |
| **MTU** | Размер пакета; кривой MTU даёт «интернет есть, сайты не грузятся». |
| **hashlimit / xt_recent** | Модули iptables для лимита подключений к 443 — базовая защита от перебора. → [04 Firewall](../docs/04-сеть-серверы/firewall-ddos.md) |
| **XDP** | Фильтрация пакетов в ядре до сетевого стека: держит объёмные атаки. |
| **ipset / geo-block** | Блокировка по странам списками подсетей. |
| **Caddy / Nginx / HAProxy / Traefik** | Реверс-прокси перед панелью, вебхуками, кабинетом и сабкой. → [04 Реверс-прокси](../docs/04-сеть-серверы/reverse-proxy.md) |
| **Selfsteal-сайт** | Настоящий сайт-заглушка на 443, который видят проверяющие вместо VPN. |
| **YABS / bench.sh / iperf3** | Стандартные тесты VPS: диск, сеть, CPU. → [05 Тесты VPS](../docs/05-хостинги/тесты-vps.md) |
| **ipregion / censorcheck** | Проверка, как видят твой IP сервисы и не в блоке ли он. → [07 Чекеры](../docs/07-скрипты/чекеры.md) |
| **Ёмкость ноды** | Сколько юзеров держит конкретное железо — цифры из практики. → [05 Ёмкость нод](../docs/05-хостинги/ёмкость-нод.md) |

</details>
