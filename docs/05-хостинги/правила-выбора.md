- ТСПУ стоит везде в РФ: «ТСПУ есть везде» [id=327293], «На всех ру-нодах тспу» [id=435274], «Во 100% случаев» [id=271353]. Уточнение 18.08: «ТСПУ есть у всех хостеров, но настроено по-разному, где-то сильнее где-то слабее» [id=1140025]; «ТСПУ не на хостингах, а на магистралях» [id=532751]; «ТСПУ не стоит в овх, он стоит в рф на магистральных» [id=1083643].
- «У тебя везде тспу стоит в рф. Без него ты просто не разместишь сервера в ДЦ… по мимо тспу у тебя ещё СОРМ должен быть» (хостер Waicore) [id=305482].
- Белые списки (БС) на L3 не обходятся VPN/прокси/SNI-подменой — «оставляется только разрешённый список IP» [id=38142..38155,158195]. «Метод подмены SNI уже давненько почти нигде не работает» [id=55144..55182].
- Правила выбора хостеров (14.08): 1) иностранные, не принимающие СБП/ру-карты; 2) у российских брать только российские локации; 3) ноды у разных хостеров для диверсификации [id=1114892].
- Гайд 25.07 «чтобы не снесли»: Hetzner/OVH не брать под их оригинальным ASN (оба 16кб-блок); только их подсеть под другим ASN [id=964242]; домен не должен содержать слова VPN [id=1174590,464264].
- «Мост лучше, чем менять серверы каждую неделю» [id=940760]; «основной всегда дабл» [id=940855].
- Правило BTorrent/скорость: не светить speedtest/не дудосить с ноды [id=1159560]; включать BBR при перегрузе 500+ юзеров [id=408005].
