<!-- /KB:HEAD -->

- **@bschekbot** (BSCHEKER) — проверка доступности сервера/домена/IP/VPN-конфига из РФ-мобильной сети (T-Mobile, МегаФон, МТС, Билайн, Tele2); IP/домен, скан подсетей CIDR и списков пачкой; VPN-конфиги VLESS/Reality/Hysteria2/VMess/Trojan/Shadowsocks/MTProxy [id=568628].
- **@cheburcheck_bot** — проверка по IP/подсети/ASN в списках блокировок, inline; на основе github.com/LowderPlay/cheburcheck; сайт cheburcheck.ru [id=563551].
- **@Latency_Lab_bot** — бот пинга; карта ограничений map.latencylab.ru [id=749395].
- **@ipregion_bot** — whois/гемини-подобный поиск [id=337369].
- **@dpi_checker_robot** (@ultima_checker_bot) — чекает доступность VLESS по регионам РФ [id=1117396].
- **@LudkaIPbot** — бот-лудка для выбивания IP по подсети [id=252443].
- **@spoofshopbot** — парсер БС айпи [id=370203].
- **@aezamonitor_bot** — мониторинг аезы [id=553577].
- **@checkburbot** — чекер BS от Moritz Zimmerman (28.07) [id=981043].
- **chebur.me / cheburcheck.ru / bs.stopsliv.lol** — веб-чекеры БС [id=327751,956985].
- **https://hyperion-cs.github.io/dpi-checkers/ru/tcp-16-20/** — чекер TCP 16-20 (белые списки) [id=239781].
- **https://hyperion-cs.github.io/dpi-checkers/ru/ipv4-whitelisted-subnets/** — IPv4 whitelisted subnets [id=239781].
- **bgp.tools** → вставить IP → раздел Connectivity (показывает, что «Швеция» у p2g/vibehost — Германия) [id=400471].
- **check-host.net** — репорты для ддос-пруфов [id=1004362].
- **IP.Check.Place** — IP-чекер [id=330543].
- **ip.check.place** — смотреть гео/IP [id=879040].
- **IPQuality (Check.Place -EI)** [id=179704].
- **node-diagnostic** (github.com/Case211/node-diagnostic) — 27 проверок ноды (живая скорость 1/4-flow + мульти-CDN, CPU steal, PSI, UDP-дропы, BBR, MSS-коллапс, accept-queue, PMTU, туннели WG/NetBird, репутация IP) [id=923728].
- **thelok1s.github.io/ru-whitelist-check/** — проверка БС (иногда врёт) [id=386954].
- **github.com/hxehex/russia-mobile-internet-whitelist/blob/main/cidrwhitelist.txt** — база CIDR масок БС [id=338059].
