- ТСПУ пропускает первые 16 КБ данных, потом рвёт соединение к IP [id=159322](https://t.me/c/2941121338/159322); «16-20 блок» банит подсети целиком у части хостеров (picky/waicor/OVH/4vps/AWS) [id=159322, 834760](https://t.me/c/2941121338/159322); в 16-20 блоке нода пингуется, но подключения не работают [id=932215](https://t.me/c/2941121338/932215); Zombie TCP (TCP ok, данных нет) = ресурс мёртв [id=1119868](https://t.me/c/2941121338/1119868).
- БС (белые списки) работают на L3: режут связность, оставляя разрешённые IP; VPN/прокси/SNI не помогают [id=158195, 38141](https://t.me/c/2941121338/158195); подсети БС: Яндекс 51.250.0.0/17, 84.201.128.0/18, 158.160.0.0/16; VK 217.16.24.0/21, 95.163.248.0/22; Timeweb 185.39.206.0/24, 91.222.239.0/24; FirstVDS 109.73.201.0/24; EdgeCenter 95.181.182.0/24 и др. [id=183033, 118215, 406159, 406407](https://t.me/c/2941121338/183033).
- Сканер IP на Яндексе: «если видят docker remnawave — снесут без объяснений» [id=330824](https://t.me/c/2941121338/330824); у VDS-хостеров ТСПУ «есть у всех, но настроено по-разному» [id=1140025](https://t.me/c/2941121338/1140025); ТСПУ стоит на магистралях, не у хостера [id=1083643, 532751](https://t.me/c/2941121338/1083643).
- Проверки: censorcheck (`wget -qO- censorcheck.tlab.pw | bash`), ipregion, iperf3, yabs, IP.Check.Place, bench.sh, multitest [id=306386](https://t.me/c/2941121338/306386); тест «айпи в БС» за 1–2 минуты: `sudo python3 -m http.server 80` → открыть http://ip с мобильного [id=316447](https://t.me/c/2941121338/316447); ТСПУ через nginx: поднять nginx и `curl -v IP` с ру-сервера — если ответ неполный, ТСПУ-блок [id=1060795](https://t.me/c/2941121338/1060795); пинг не показателен, curl показателен [id=1059060](https://t.me/c/2941121338/1059060); bgp.tools/prefix/<CIDR>#connectivity [id=761458](https://t.me/c/2941121338/761458).
- WARP-туннель между РФ и заграницей ТСПУ не режет (режет на входе в РФ) — даёт подъезд к панели [id=1119394](https://t.me/c/2941121338/1119394); WireGuard в РФ: классический WG «изи блочат» [id=991594](https://t.me/c/2941121338/991594); схема VLESS IN → WireGuard OUT: сервер на бегете, вход VLESS, выход WG — работает 50/50 на ру, 100% на иностранных [id=1041345](https://t.me/c/2941121338/1041345).
- AmneziaWG v2 шлёт мусор, работает; L2TP/IPSec на БС-серверах работают [id=643309, 865797](https://t.me/c/2941121338/643309).
- CDN-обход БС: только GET/HEAD/OPTIONS (PUT/POST режут), Яндекс CDN основной + MWS резервный; трафик ~0.8–1₽/ГБ; скорость до 500 Мбит/с [id=653372, 689850, 744433](https://t.me/c/2941121338/653372); тарификация Яндекса: 150₽/мес — 150 ГБ + 100 млн запросов, далее ~1₽/ГБ и 1₽/100k запросов [id=781077..781088, 755292](https://t.me/c/2941121338/781077); аккаунты-пустышки с грантом ~500₽ держатся 2–3 ТБ [id=913548](https://t.me/c/2941121338/913548); VK CDN коды: 429 = rate-limit/плохой кэш, 451 = полный бан [id=1173257](https://t.me/c/2941121338/1173257); билайн банит при отсутствии кэша (403) [id=1172950](https://t.me/c/2941121338/1172950); CDN эджи надо подбирать (регион/оператор), список префиксов Яши: tech.cdn.yandex.net/prefixes/yc.json [id=838538, 838544](https://t.me/c/2941121338/838538).
- Мост (RU→EU): vless-влесс пинг нулевой, vless-ss при нехватке ОЗУ [id=341934](https://t.me/c/2941121338/341934); SS-мост банится на большинстве провайдеров [id=439173](https://t.me/c/2941121338/439173); hysteria2 хорош для мостов при потерях, но реже на скорости [id=378320..378526](https://t.me/c/2941121338/378320); конфиг моста (дословный, RU→DE SS) [id=415500](https://t.me/c/2941121338/415500):

- Балансер Xray (клиент/сервер): leastLoad + burstObservatory, costs для fallback, fallbackTag — один outbound [id=328458, 487826, 584231, 874749..874754](https://t.me/c/2941121338/328458):
```json
"balancers": [{ "tag": "auto-lte", "selector": ["lte", "proxy"],
  "strategy": { "type": "leastLoad", "settings": {
    "costs": [ {"match": "lte-lc", "value": 1000}, {"match": "proxy", "value": 1} ],
    "maxRTT": "1s", "tolerance": 0.35 } }, "fallbackTag": "direct" }],
"burstObservatory": { "pingConfig": { "timeout": "3s", "interval": "1m", "sampling": 1,
  "destination": "http://www.gstatic.com/generate_204" }, "subjectSelector": ["proxy"] }
```
`selector` и `subjectSelector` — префиксные матчеры по началу тега; `costs` только внутри leastLoad [id=874748](https://t.me/c/2941121338/874748).
- Мульти-CIDR проверка подсетей (multi CIDR scan) — TCP-пинг ≠ «ворк» [id=469795, 715776..715897](https://t.me/c/2941121338/469795).
- ТСПУ MITM: подсовывает настоящий сертификат маскировочного сайта; в логах `REALITY: received real certificate (potential MITM or redirection)` [id=643295, 644289](https://t.me/c/2941121338/643295).
- Итог по транспорту (04.08.2026): нужны vless raw и vless xhttp (raw на обычные серверы, xhttp под CDN); grpc решает параллельные соединения; самый живучий — grpc tls [id=1036816, 1039135](https://t.me/c/2941121338/1036816).
