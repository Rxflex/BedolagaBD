- **[id=196085|26.01.2026]** TrafficGuard автоустановка: `curl -fsSL https://raw.githubusercontent.com/DonMatteoVPN/TrafficGuard-auto/refs/heads/main/install-trafficguard.sh | sudo bash` → команда `rknpidor`.
- **[id=201328|Colombo|10.08.2026]** «Съёмка скринов» — «Скрипт связи чата» (https://t.me/ctokenvbnm).
- **[id=195551|19.08.2026]** «Скрипт selfsteal на каждую локацию» (универсальный для всех панелей и чистого xray): https://github.com/begugla0/selfsniscripts.
- **[id=1142735|—|09.08.2026]** «Mitelis» (мелис + 0.7%/мес): «nether».
- **[id=199459|15.08.2026]** Speedtest: `wget -qO- bench.gig.ovh | bash` / `wget -qO- bench.tlab.pw | bash` / `wget -qO- bench.sh | bash`.
- **[id=196891|27.01.2026]** IP Checker: `bash <(curl -Ls IP.Check.Place) -l en`.
- **[id=196898|27.01.2026]** Censorcheck: `bash <(wget -qO- https://github.com/vernette/censorcheck/raw/master/censorcheck.sh) --mode geoblock` / `--mode dpi`.
- **[id=196899|27.01.2026]** YABS: `curl -sL yabs.sh | bash -s -- -4`.
- **[id=196892|27.01.2026]** Russian iperf: `bash <(wget -qO- https://github.com/itdoginfo/russian-iperf3-servers/raw/main/speedtest.sh)`.
- **[id=206914|27.01.2026]** TrafficGuard: https://github.com/dotX12/traffic-guard.
