## Детект uTLS / fingerprint / TLS-in-TLS · Часть A

- **[id=581441..585946|25-26.05.2026]** ТСПУ отбрасывает VLESS TCP Reality с фингерпринтом **chrome**; смена fingerprint в Remnawave → Хосты → расширенные (chrome → firefox / safari / qq / android / ios / random / randomized); «qq fp для РФ максимально палевный» [id=582124]; «рандомайзед пашет вроде везде» [id=585579].
- **[id=582273]** Возможная причина — патч ядра Xray: https://github.com/XTLS/Xray-core/pull/6181.
- **[id=593471|Wyatt Haley|27.05.2026]** «Банят не только fingerprint. Целятся опять в tls 1.3, и походу конкретно в tls in tls, от того реалити подобные подключения падают».
- **[id=595427|Дима+|28.05.2026]** «Сейчас отрезали хром потому что в xray core использовалась устаревшая версия fingerprint хрома, в новых релизах обновят и снова всё заработает... если будут резать весь хром — заблочат самый популярный браузер, вряд ли».
- **[id=595294|Glück|28.05.2026]** Смена fp на firefox/qq/edge — «это лечит лишь симптом»; xs «/grpc бы уже давно прикрыли» (но не прикрыли), «xhttp будет жить вечно пока cdn есть».
- **[id=643295|Данил|05.06.2026]** ТСПУ начали блокировать прокси-сервера методом активного спуфинга: перехватывают TLS-рукопожатие и подсовывают клиенту настоящий сертификат маскировочного сайта.
- **[id=643462|compact disc|05.06.2026]** В Xray убрали allowInsecure; см. verifyPeerByCertName — серт должен совпадать с SNI.
- **[id=646031|—|05.06.2026]** В бегете «частичные проблемы» из-за ТСПУ (официальное сообщение Бегета, SpaceWeb, Datacheap, Timeweb о возможной блокировке их сетей).
- **[id=646160|—|06.06.2026]** Эксперимент Сергея: с обычным SNI серверы банят почти сразу (IP на выброс), с селфстилом не трогают; при этом селфстил не панацея.
- **[id=647601|YungCayde|06.06.2026]** WAF CDN-ки (Билайн) 403 и закрывает соединение, если видит UUID в заголовке/path/query; у grpc нет uuid в открытом виде — поэтому пускает; websocket в билайне не пускает.
- **[id=648042|06.06.2026]** Yandex Cloud: хорошо настроенный XHTTP живёт дольше, чем TCP+Reality; банки не частые.
- **[id=647529|pon arķ|06.06.2026]** На СДН возможен grpc reality; xhttp тоже.
- **[id=643342|Дениска|10.07.2026]** `curl -v https://domain` даёт `SSL_ERROR_SYSCALL`; `curl -v http://domain` даёт `(52) Empty reply from server` — прямая ТСПУ-резка сервера.
- **[id=726992|ТОЧНА НЕ ВПН|21.06.2026]** РКН забанил телеграм → панель ремны не может подключиться к серверам и просто крашится на РФ VPS.
- **[id=858450..858465|12-13.07.2026]** Продавцы Beeline CDN конфигураций: «100% обходят 403, блокировку по UUID, "/" и другие паттерны антифрода; только метод GET; правильная настройка заглушек критична».
- **[id=834456..834459|07.08.2026]** Регулярки, которыми билайн резал xray:
  ```
  ^.*(\/\?[^&]*&[^&]*)$
  (\/(?:[^\/]+\/\d+|\d+\/[^\/]+))$
  ```
