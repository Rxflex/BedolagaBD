## Remnawave 3.0 (Breaking change) · Часть B

- **[id=1032520|Egor|03.08.2026](https://t.me/c/2941121338/1032520)** Полный переход на Remnawave 3.0.0 — ломающий релиз: панель убрала uuid из пользователей, адресация только по числовому id; старый бот шлёт UUID, панель отвечает 400 expected number, received NaN.
- **[id=1032536|Egor|03.08.2026](https://t.me/c/2941121338/1032536)** Команды обновления v4.0.0:
  ```text
  .env: TRAFFIC_EXCLUDED_USER_UUIDS → TRAFFIC_EXCLUDED_USER_IDS, временно GRACE_ACCESS_MODE=drain
  # Бот (в папке с ботом!)
  git pull
  docker compose build bot
  docker compose stop bot
  docker compose run --rm bot alembic upgrade head
  docker compose run --rm bot python -m scripts.backfill_remnawave_ids           # dry-run
  docker compose run --rm bot python -m scripts.backfill_remnawave_ids --apply   # запись
  docker compose up -d bot
  ```
- **[id=1032713|Egor|03.08.2026](https://t.me/c/2941121338/1032713)** Grace-доступ: crash-safe ограниченный доступ для истёкших/лимитированных подписок.
