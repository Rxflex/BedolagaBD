## 3.1 Reshala-Remnawave-Bedolaga

github.com/DonMatteoVPN/Reshala-Remnawave-Bedolaga [id=118048, 228448]. Оценка сервера (сколько юзеров потянет), UFW/fail2ban, BBR, шейпер. Установка:
```bash
wget -O install.sh https://raw.githubusercontent.com/DonMatteoVPN/Reshala-Remnawave-Bedolaga/main/install.sh \
  && bash install.sh \
  && reshala
```
[id=139655, 389227]. «Решала-скрипт» имеет платную поддержку (топик /30933) [id=491327].

Шейпер трафика (docs/Sheiper_trafik.md, [id=138463, 332187, 357912]):
- v2.58+: персональные лимиты, каждый юзер свои N Мбит, потоки/buckets, DL/UL
- v2.90+: multi-rule eBPF шейпер (EDT, до 32 правил, статика/динамика с burst + штраф 0.5 МБ/с на 60с, L3, IPv6, 0% коллизий vs tc+u32); меню reshala → [2]
- Меню: `[2] Шейпер трафика` → Добавить лимит
- ВНИМАНИЕ: BBR3 (кастомное ядро) не имеет TC модулей — шейпер не заведётся; откатывать ядро [id=138513]
- Перед созданием нового конфига шейпера удалить старый [id=321653]

Другие ветки Решалы:
- Reshala-AI-ticket-bot (github.com/DonMatteoVPN/Reshala-AI-ticket-bot) — ИИ-ассистент поддержки [id=228388, 458948]. Спор в чате: «ai решала в бедолаге встроена?» — нет, это отдельный бот [id=459859].
- reshala-script (github.com/DonMatteoVPN/reshala-script) — тесты, шейдер (5-й пункт меню) [id=198609, 197090].
- Reshala-Remnawave-Bedolaga поставил (f2b/ufw/bbr/шейпер) на каждую ноду [id=239287].
- v3.047 «Глубоко эшелонированная оборона»: глобальный whitelist с контрольными суммами, Geo-Block ipset, Firewall UFW + Docker Fix, Fail2Ban через UFW, SSH Manager, Skynet (Remote) [id=513417].
- Решала v3.016 «маскировщик лендинг-страниц Бедолаги»: лендинг за мусорным бесплатным доменом (пример https://lendinghello.mooo.com) [id=489095].
- v3.021→v3.025: Kernel Hardening `rp_filter: 2 (strict) → 0 + src_valid_mark=1` (фикс «WireGuard/WARP handshake есть, но трафик не идёт»), после апдейта `sysctl -p /etc/sysctl.d/99-reshala-hardening.conf` [id=495106].

## 3.2 Traffic Guard и брандмауэры

- `dotX12/traffic-guard` [id=196021, 199450, 228476] — анти-скан, работает с ufw/netfilter-persistent. Установка:
```bash
curl -fsSL https://raw.githubusercontent.com/dotX12/traffic-guard/master/install.sh | sudo bash
```
[id=425374]. Форк авто-инсталлера: `DonMatteoVPN/TrafficGuard-auto` (`curl -fsSL …/install-trafficguard.sh | sudo bash`, команда `rknpidor`) [id=197089, 277810].
- Блоклисты Traffic Guard: `shadow-netlab/traffic-guard-lists` [id=1094546]; автор ведёт исходящий трафик на ВК/Мейл, живущий в списках: `AndreyTimoschuk/nonorkn` [id=650493].
- CrowdSec (thegrayfoxxx/configs, Debian 12/13, в докере; LAPI защиты нет на основной ноде; lapi.sh — LAPI launcher + Traffic Guard; node.sh; Traffic Guard загружает блоклисты в CrowdSec через `cscli decisions import`; коллекция crowdsecurity/iptables — заменяет fail2ban и traffic-guard) [id=627172, 690898].
- Astracat_Protect-WAF (github.com/ASTRACAT2022/Astracat_Protect-WAF) — бесплатный WAF [id=625215].
- `kenshiro-pixel/vps-shield` — «вайбкодный ддос-щит»; «оставить на проде не рекомендуют» [id=651801, 651786].
- `kutovoys/xray-torrent-blocker` — блокировка торрентов (DMCA-жалобы) [id=17409, 199450]; `kutovoys/ru_gov_zapret` — РКН-реестр + инструкция docs.rw/docs/learn/zapret-ru-gov [id=65256, 92847].
- `houshmand-2005/V2IpLimit` — антиспуф по HWID/IP (читает логи ядра, следит за превышением IP) [id=144235, 140308].
- `SkunkBG/shape` — «борюсь с нарушителями на серверах БС»; ограничитель скорости по IP, TG-уведомления, SSH-туннель SOCKS для РФ-серверов, поддержка Remnawave API (23.08) [id=1096435, 1110612, 1176773].
- `syvlech/remnawave-limiter` — ограничение коннектов на юзера (антишеринг) [id=698072, 1097597, 1147110]; «по сути единственная рабочая штука» (Petros, [id=1097597]).
- `Mrvibecodic/remnawave-subscription-middleware` — прослойка между Remnawave и подпиской: пробник/грейвс сквад, лимиты по HWID/подписке, объединение двух сабок, grace access [id=702308, 846530, 1101365, 1149397].
- `zavul0nn/remnawave-grace-access` — выдаёт доступ при истёкшей подписке [id=1110601].
- `goldns/remna_sub_panel` — совмещает 2 подписки в одну в Happ; при истечении одной отключает и оставляет вторую [id=521188, 738151].
- `goldns/remna_sub_panel` = «fingerprint_qq» репа линк (авторства goldns) [id=879302].
- `BEDOLAGA-DEV/VPN-BLACKLIST` — ЧС серверов (PR#2 [id=180744], PR#9 [id=291185], PR#12 [id=355753], PR#13 [id=379550]). Использование в кабине: `BLACKLIST_CHECK_ENABLED=true`, `BLACKLIST_GITHUB_URL=https://github.com/BEDOLAGA-DEV/VPN-BLACKLIST/blob/main/blacklist.txt`, пересобрать статику [id=371253].
- `Blin4ickUSE/ban-vpn` — список ID нежелательных юзеров, интеграция с Бедолагой; обновлять раз в 60 минут [id=274368, 495751]. 12k+ забаненных в blacklist.txt [id=1166899].
- `C24Be/AS_Network_List` — список ASN/подсетей VPN-провайдеров для блокировки [id=650495].
- `hxehex/russia-mobile-internet-whitelist` — список мобильных подсетей РФ (БС/белые списки) [id=145531, 255914, 277076, 373844, 488756]. Обновляется каждый час [id=120119]. На 21.04 «половина сменилась» [id=386950].
- `zieng2/wl/blob/main/vless_universal.txt` / `vless_lite.txt` — обновляемый список [id=277076, 551629].
- `igareck/vpn-configs-for-russia` — список конфигов РФ [id=277076].
- `kutovoys/ru_gov_zapret` + `docs.rw/docs/learn/zapret-ru-gov` — реестр РКН для блокировки (обновление раз в сутки шедулером) [id=92847, 65256].
- `kutovoys/xray-torrent-blocker` — торренты.
- `internetkafe/CDN-xhttp` — сборка Xray с патчами (слеш в конце пути) [id=780595].
- `DigneZzZ/geoblock` — скрипт геоблока, популярный [id=805637].
- `internetkafe/vpnhostinglist` — список VPN-хостеров [id=784567].
