## 3.1 Reshala-Remnawave-Bedolaga

github.com/DonMatteoVPN/Reshala-Remnawave-Bedolaga [id=118048, 228448](https://t.me/c/2941121338/118048). Оценка сервера (сколько юзеров потянет), UFW/fail2ban, BBR, шейпер. Установка:
```bash
wget -O install.sh https://raw.githubusercontent.com/DonMatteoVPN/Reshala-Remnawave-Bedolaga/main/install.sh \
  && bash install.sh \
  && reshala
```
[id=139655, 389227](https://t.me/c/2941121338/139655). «Решала-скрипт» имеет платную поддержку (топик /30933) [id=491327](https://t.me/c/2941121338/491327).

Шейпер трафика (docs/Sheiper_trafik.md, [id=138463, 332187, 357912](https://t.me/c/2941121338/138463)):
- v2.58+: персональные лимиты, каждый юзер свои N Мбит, потоки/buckets, DL/UL
- v2.90+: multi-rule eBPF шейпер (EDT, до 32 правил, статика/динамика с burst + штраф 0.5 МБ/с на 60с, L3, IPv6, 0% коллизий vs tc+u32); меню reshala → [2]
- Меню: `[2] Шейпер трафика` → Добавить лимит
- ВНИМАНИЕ: BBR3 (кастомное ядро) не имеет TC модулей — шейпер не заведётся; откатывать ядро [id=138513](https://t.me/c/2941121338/138513)
- Перед созданием нового конфига шейпера удалить старый [id=321653](https://t.me/c/2941121338/321653)

Другие ветки Решалы:
- Reshala-AI-ticket-bot (github.com/DonMatteoVPN/Reshala-AI-ticket-bot) — ИИ-ассистент поддержки [id=228388, 458948](https://t.me/c/2941121338/228388). Спор в чате: «ai решала в бедолаге встроена?» — нет, это отдельный бот [id=459859](https://t.me/c/2941121338/459859).
- reshala-script (github.com/DonMatteoVPN/reshala-script) — тесты, шейдер (5-й пункт меню) [id=198609, 197090](https://t.me/c/2941121338/198609).
- Reshala-Remnawave-Bedolaga поставил (f2b/ufw/bbr/шейпер) на каждую ноду [id=239287](https://t.me/c/2941121338/239287).
- v3.047 «Глубоко эшелонированная оборона»: глобальный whitelist с контрольными суммами, Geo-Block ipset, Firewall UFW + Docker Fix, Fail2Ban через UFW, SSH Manager, Skynet (Remote) [id=513417](https://t.me/c/2941121338/513417).
