> официальные репозитории и проекты из закрепа

---
<!-- /KB:HEAD -->

Официальные репо: `remnawave/panel`, `BEDOLAGA-DEV/remnawave-bedolaga-telegram-bot`, `BEDOLAGA-DEV/bedolaga-cabinet` [id=93414, 183337].
Полезные проекты из закрепа (список дублируется регулярно [id=16246, 230805, 318081, 464551, 684162, 726479, 835847]):
- `kutovoys/xray-checker` — чекер живости нод/конфигов из подписки (xray-checker.kutovoy.dev); НЕ поддерживает hysteria2, плохо работает с трояном, по пингу врёт, ~3 мес без обнов [id=698072]
- `eGamesAPI/remnawave-reverse-proxy` — автоустановка панели/ноды/selfsteal одной командой, ~3 мин с нодой [id=17773]
- `Jolymmiels/remnawave-telegram-shop` — магазин подписок
- `machka-pasla/remnawave-tg-shop` — «бот от мачки»: проще в настройке, меньше функционала, на вебхуках [id=17023]
- `DigneZzZ/remnawave-scripts` — скрипты: смена ядра Xray, selfsteal.sh, remnanode.sh, README-selfsteal.md [id=16246, 313924, 31674]
- `distillium/remnawave-backup-restore` — бэкап/восстановление/миграция панели (v4.0.0 на 21.08 [id=1160274])
- `maposia/remnawave-telegram-sub-mini-app` — кастомная сабка; v2.2.5 после React-уязвимости в miniapp [id=93414]
- `legiz-ru/my-remnawave` — кастомные сабки, mihomo-rule-sets, орion [id=1420, 62125]
- `dotX12/traffic-guard` — анти-скан/анти-ДДОС iptables-фильтр [id=196021]
- `BEDOLAGA-DEV/VPN-BLACKLIST` — ЧС серверов/мошенников (blacklist.txt 1220+ ID [id=397432])

Список звёзд BEDOLAGA на GitHub (экосистемная страница): remnawave/panel, BEDOLAGA-DEV/bot, BEDOLAGA-DEV/cabinet, kutovoys, eGamesAPI, Jolymmiels, machka-pasla, DigneZzZ, distillium, maposia, legiz-ru [id=146145, 221213].
Партнёрства (2025–2026): Platega (менеджер @ArstanPlatega), RollyPay (rollypay.io, @sasha_rollypay), WATA (промокод `bedolaga`) [id=277830, 625807].

RemnaCore — будущая модульная система на Go + wasm-плагины, гексагональная DDD: github.com/BEDOLAGA-DEV/RemnaCore (анонс [id=321511, 322409], «умный плагин миграции» [id=322421]).
