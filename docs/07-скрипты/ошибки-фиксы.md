> самое частое по скриптам

---
<!-- /KB:HEAD -->

- «Подпись не совпала…» (YooKassa) — `YOOKASSA_WEBHOOK_SECRET=` оставить ПУСТЫМ (юкасса не шлёт подпись, проверять нечего) [id=55579..55581, 17730].
- CryptoBot «Неверная подпись» — закомментировать CRYPTOBOT_WEBHOOK_SECRET [id=17604, 7828].
- TelegramConflictError: can't use getUpdates while webhook is active — удалить вебхук `https://api.telegram.org/bot<TOKEN>/deleteWebhook` [id=25745, 154955].
- 401 «webhook с неверным секретом» — openssl rand -hex 32 → WEBHOOK_SECRET_TOKEN, deleteWebhook, `make reload` [id=58756].
- `Bad Request: bad webhook: Failed to resolve host` — DNS у хостера (spaceweb-веха 04.04.2026); фикс: домен у нормального хостера / A-запись / сменить DNS [id=321739, 323407].
- `Failed to resolve host` после обновления — DNS временно не резолвится, проходит само через ~30 мин [id=391335].
- 405 на /yookassa-webhook — норм (Method not allowed = слушает) [id=20408].
- `{"status":"ok","message":"YooKassa webhook endpoint is working"…}` — норм ответ на GET [id=36879].
- `ValueError: path should be started with / or be empty` — слеш убрать в webhook path env [id=20680, 35140].
- Поллинг работает, вебхук нет — чаще всего реверс-прокси не настроен или DNS [id=353799, 416941].
- Юкасса webhook IP-allowlist: `YOOKASSA_TRUSTED_PROXY_NETWORKS=185.71.76.0/24,185.71.77.0/24` [id=631299].
- WATA IP-allowlist: 62.84.126.140, 51.250.106.150 [id=869754].
- Platega Callback URL в кабинете — «именно с путём, голый домен не работает» [id=156206..156218].
- Lava Base URL = `https://api.lava.ru` (старый gate.lava.ru не существует); рабочие эндпоинты `/business/invoice/create|status` (только Business-аккаунт) [id=497090, 497808].
- Бесплатный `WEBHOOK_SECRET_TOKEN` и юкасса — см. выше.
- «Ремна-вебхуки отдали Test notification sent, но в ТГ-группу не пришло» — настроить NOTIFICATIONS_TOPIC в боте [id=507320].
- `BEDOLAGA_API_URL=` = `WEBHOOK_URL` (или /api) для кастомной кабины [id=542232, 541888].
- FreeKassa webhook: warning `Freekassa webhook: недоверенный IP` — добавить IP платёжки в доверенные [id=445641].
- RollyPay webhook: URL настраивается при создании кассы; nginx: `location = /rollypay-webhook { proxy_pass http://127.0.0.1:8080; … }` [id=424623, 456089].
- Overpay env: OVERPAY_ENABLED=false; OVERPAY_USERNAME; OVERPAY_PASSWORD; OVERPAY_PROJECT_ID; OVERPAY_P12_PATH=/app/certs/client.p12; OVERPAY_P12_PASSPHRASE; OVERPAY_API_URL=https://api.overpay.io; OVERPAY_PAYMENT_METHODS=card,fps; OVERPAY_DISPLAY_NAME=Overpay; OVERPAY_CURRENCY=RUB; OVERPAY_MIN_AMOUNT_KOPEKS=10000; OVERPAY_MAX_AMOUNT_KOPEKS=100000; OVERPAY_WEBHOOK_PATH=/overpay-webhook; OVERPAY_RETURN_URL=; OVERPAY_LIFETIME_MINUTES=… [id=392083]
- Platega env (рабочие ключи): PLATEGA_ENABLED=true; PLATEGA_MERCHANT_ID=; PLATEGA_SECRET=; PLATEGA_BASE_URL=https://app.platega.io; PLATEGA_DISPLAY_NAME=Platega; PLATEGA_RETURN_URL/FAILED_URL; PLATEGA_CURRENCY=RUB; PLATEGA_ACTIVE_METHODS=2,10,11,12,13; PLATEGA_MIN_AMOUNT_KOPEKS=100; PLATEGA_MAX_AMOUNT_KOPEKS=100000000; PLATEGA_WEBHOOK_PATH=/platega-webhook; PLATEGA_WEBHOOK_HOST=0.0.0.0; PLATEGA_WEBHOOK_PORT=8086 [id=168180, 156206]
