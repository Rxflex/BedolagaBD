Рабочие шаги install_bot.sh [id=21099..21102, 35081..35119](https://t.me/c/2941121338/21099):
```bash
git clone <bedolaga-repo> && cd <dir>
mkdir -p ./logs ./data ./data/backups ./data/referral_qr uploads/images uploads/videos uploads/thumbnails
chmod -R 755 ./logs ./data uploads
sudo chown -R 1000:1000 ./logs ./data uploads
./install_bot.sh
# пункт (8) — настроить обратный прокси (монтирует файлы, куки-ключ, серты), управляет Caddy, делает бекапы перед правками
```
Известные фейлы install_bot.sh: «No such file or directory» .env (создать из .env.example вручную [id=31964](https://t.me/c/2941121338/31964)); PermissionError data/backups (права выше [id=35081](https://t.me/c/2941121338/35081)); «Не удалось экспортировать БД» при бэкапе [id=25419](https://t.me/c/2941121338/25419); пропущенный шаг (id=29697 «Я нашел»); «все env в одну кучу пихает» [id=31771](https://t.me/c/2941121338/31771).
