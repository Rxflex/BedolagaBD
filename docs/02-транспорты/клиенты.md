## Happ
- Крипто-линк шифрование подписки: первые 100 юзеров бесплатно, дальше 0.0738$/юзер [id=708276|omae|17.06.2026](https://t.me/c/2941121338/708276); дешифратор @Happ4decryptbot [id=708308](https://t.me/c/2941121338/708308).
- Happ свой DNS не читает, юзает Cloudflare; INCY использует DNS из json профиля [id=659037|c0mrade|09.06.2026](https://t.me/c/2941121338/659037).
- Happ пингует все сервера на 8.8.8.8 → пинг в хаппе недостоверен (500 в Happ vs 59 в speedtest) [id=357552|13.04.2026](https://t.me/c/2941121338/357552); Happ пинг по HTTP, INCY по TCP по умолчанию; в INCY поставить HTTP-пинг — цифры как в Happ [id=660623/660625|INCY|09.06.2026](https://t.me/c/2941121338/660098/660623).
- Утечка: на Happ по умолчанию нет авторизации socks5/http инбаундов — легко утекает выходной IP; в INCY авторизация автоматом (yourvpndead, github.com/loop-uh/yourvpndead) [note_069|20.04.2026].
- iOS лимит 50 МБ JSON; category-ads-all крашит; роутинг-фиксы [id=380614..380651|20.04.2026](https://t.me/c/2941121338/380614).
- Выключение роутинга у всех клиентов: Happ-фича «поставил роутинг — хуй выключишь всем»; решение `routing-enable false` в настройках подписки [id=741487, 741495|24.06.2026](https://t.me/c/2941121338/741487).
- При применении роутинга хапп-роскомвпна не работает при включенных шаблонах JSON [id=729276|Vladislav A|21.06.2026](https://t.me/c/2941121338/729276).
- Happ dev-ветка: проблем с xhttp нет, 16 часов на XHTTP Reality Auto на iOS [id=652993|Stanislav Torichnev|07.06.2026](https://t.me/c/2941121338/652993); в хаппе можно отключить лимит для xhttp (dev settings), но настройка не воркает → переезд на tcp [id=651628|okala|07.06.2026](https://t.me/c/2941121338/651628).
- Happ не хочет работать адекватно на 2.8.0 remnanode; в INCY всё гуд [id=777111|Лев|30.06.2026](https://t.me/c/2941121338/777111).
- Приложение «не поддерживается» в INCY: HWID либо отключить в настройках страницы подписки, либо использовать приложение с hwid [id=755040/755047|01.07.2026](https://t.me/c/2941121338/755040).

## INCY
- Поддержка протоколов: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, SOCKS5, WireGuard; план: AmneziaWG и olcrtc в следующей версии [id=660506|INCY|09.06.2026](https://t.me/c/2941121338/660098/660506); AmneziaWG (avg) завезли в 3.2.0 [id=665603|INCY DVP|10.06.2026](https://t.me/c/2941121338/665603).
- Ядро: ласт Xray на последнем коммите; XHTTP-значения изменены (PR #6258) — старые XHTTP+CDN конфиги могут не работать; поддерживает и новые, и старые поля [id=697609|15.06.2026](https://t.me/c/2941121338/697609).
- Авторутинг: в настройках подписки (дополнительные хэдеры) ключ autorouting, значение `incy://autorouting/onadd/https://raw.githubusercontent.com/hydraponique/roscomvpn-routing/refs/heads/main/INCY/DEFAULT.JSON`; Happ этот хэдер не понимает [id=745065|24.06.2026](https://t.me/c/2941121338/745065).
- Рабочая строка автороутинга (дока частично врёт): `incy://autorouting/onadd/https://raw.githubusercontent.com/hydraponique/roscomvpn-routing/master/INCY/DEFAULT.JSON` — URI прописывать и в заголовок, и в тело подписки; конвертация raw.githubusercontent не работает [id=797127|03.07.2026](https://t.me/c/2941121338/797127).
- INCY не читает/не применяет json-роутинг как Happ: с маршрутизацией через json не работает, без — работает [id=753886/753917/755335|01.07.2026](https://t.me/c/2941121338/753886).
- DNS-роутинг в INCY сломан: если в конфиге Xray блок `dns` (встроенный DNS-аутбаунд), ДНС-запросы вообще не попадают в роутинг и идут напрямую; в Happ/v2rayN/голом ядре — по доке. Решение: убрать `dns` из конфига [id=843810/844763|Артём Соломатин|12.07.2026](https://t.me/c/2941121338/843810).
- Диплинк: `incy://import/{{SUBSCRIPTION_LINK}}` [id=708344|e|17.06.2026](https://t.me/c/2941121338/708344); с автороутингом: `incy://import/{{SUBSCRIPTION_LINK}}?autorouting=incy://autorouting/onadd/...` [id=758734|27.06.2026](https://t.me/c/2941121338/758734).
- Иконки для сабпейджа: набор 50 SVG github.com/INCY-DEV/incy-icons; репо релизов github.com/INCY-DEV/incy-platforms (desktop-v3.2.2, Win пре-альфа) [id=743947, id=658768|09.06.2026](https://t.me/c/2941121338/743947); доки docs.incy.cc [id=751937|01.07.2026](https://t.me/c/2941121338/751937).
- Пинг INCY по TCP по умолчанию [id=660623|09.06.2026](https://t.me/c/2941121338/660098/660623); «xray tun в INCY пока нет» [id=794690|03.07.2026](https://t.me/c/2941121338/794690).
- Патченный INCY без добавления `/` в конце (Android) — «больше для личного» [id=779970|Deaddos|01.07.2026](https://t.me/c/2941121338/779970).
