> серверные и клиентские правила, domainStrategy

---
<!-- /KB:HEAD -->

- Классические правила ноды: `geoip:private → BLOCK`, `bittorrent → BLOCK`, `geoip:ru → DIRECT`, `geosite:category-ru → DIRECT` [note_010, note_014, note_020].
- Серверный routing `{"ip": ["geoip:ru"], "outboundTag": "DIRECT"}` гоняет РУ-трафик через ноду (outbound freedom), не напрямую с телефона; клиентский DIRECT — только через клиентские роутинги [id=157287..157294, 157247..157249|09.11.2025].
- Happ routing (пример) [id=15648|Андрей|25.09.2025]: DirectSites/ProxySites (geosite: CATEGORY-GOV-RU, CATEGORY-MEDIA-RU, YOUTUBE, OPENAI, INSTAGRAM; DirectIp: private ranges + geoip:RU; DomainStrategy IPIfNonMatch, FakeDNS false).
- «Happ routing не юзаем — вместо него Xray json» [id=446374..446377|Frist|27.04.2026]; Happ-роутинг «гавно», роутинг через JSON Advanced [id=509443|14.05.2026].
- Серверный routing с leastPing-балансером (RUMSK/RUNSK inbounds → balancer → fallback DIRECT) [id=653971/654001|08.06.2026]:
```json
"routing": {"rules":[
  {"ip":["geoip:private"],"outboundTag":"BLOCK"},
  {"ip":["geoip:ru"],"outboundTag":"DIRECT"},
  {"inboundTag":["RUMSK_VLESS_INBOUND","RUMSK_Trojan_Inbound","RUNSK_VLESS_INBOUND","RUNSK_Trojan_Inbound"],"balancerTag":"Balancer"}],
 "balancers":[{"tag":"Balancer","selector":["PROXY"],"strategy":{"type":"leastPing"},"fallbackTag":"DIRECT"}],
 "domainStrategy":"IPIfNonMatch"}
```
- Клиентский роутинг на РУ-сервисы: огромный список доменов VK/OK/Mail/Dzen/Sber/Ozon/Avito/T-Bank/WB/Yandex/VTB/Alfa/RZD/Pochta/Gosuslugi/X5/HH → direct — «засерает память клиента» [id=654001|08.06.2026].
- RU-домены можно не блокировать, а отправлять в директ у клиента (роутинг прилетает с подпиской) [id=576459,576516,576524|24.05.2026].
- Настройка БС по ip: geoip private покрывает часть, остальное в списке «224.0.0.0/3» [id=782775|kataomi|~02.07.2026].
- Gemini через WARP-outbound: домены gemini.google.com, generativelanguage.googleapis.com, aistudio.google.com и др.; можно geosite:google-gemini или category-ai-!cn [id=340457|хеуклер|08.04.2026].
- iOS: category-ads-all в роутинге вызывает проблемы (800k строк не разбирается) — замена на category-ads [id=697509|INCY DVP|15.06.2026].
