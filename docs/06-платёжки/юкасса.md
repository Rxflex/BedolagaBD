- Ротация платежек — суточный/месячный/годовой лимит приёма средств; при достижении лимита платёжка автоматически скрывается до начала следующих суток [id=1036754](https://t.me/c/2941121338/1036754).
- Требование перезапуска бота после включения платежки (чтобы хуки работали) [id=1093661](https://t.me/c/2941121338/1093661).
- Автоплатежи с карты: «у платеги всё автоматом, в роллипей добавили» [id=1034386](https://t.me/c/2941121338/1034386).
- Приём крипто напрямую: BNB/TON/DASH/BTC/XMR, автодетект платежа; СБП/карты — «серый процессинг» [id=1097844](https://t.me/c/2941121338/1097844).
- Приём оплат по СБП QR: подключить кассу [id=1145013](https://t.me/c/2941121338/1145013).
