### Установка с нуля — живой разбор [id=491327–492392](https://t.me/c/2941121338/491327) (11.05)
- `make up` падает на старом docker → обновить: `sudo curl -fsSL https://get.docker.com | sh`
- `docker compose` недоступен на старом compose → использовать `docker-compose up -d` (и НЕ вводить `—build` с длинным тире — «No such service: —build»)
- pydantic `MULENPAY_SHOP_ID: Input should be a valid integer` → в .env поставить 0 или закомментировать неиспользуемые платёжки; правило: «читай строку в ошибке, ищи её в .env через Ctrl+W, ставь 0 или комментируй»
- daemon не запущен → `sudo systemctl start docker` (перезагрузка не обязательна)
- **правильная пересборка**: `docker compose down && docker compose up -d --build && docker compose logs -f -t`; с чистым кешем: `docker builder prune -a -f && docker compose build --no-cache`
- изменения .env НЕ применяются рестартом ремны — нужна полная пересборка бота (`--build`), «бот не увидит изменений в апи панели без полной пересборки»
- саблинк: если в ремне SUBDOMAIN без `/api/sub`, бот выдаёт `/api/sub/...`; пусть бот выдаёт голый домен — тоже работает
