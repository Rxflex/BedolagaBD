## Период 31.07–09.08.2026 — Remnawave 3.0.0 (ломающий), Bedolaga v4.0.0, Cabinet 1.65

### Burst Observatory + XHTTP-inject (Remnawave panel) [id=1007907]
```json
"remnawave": {
    "injectHosts": [
      {
        "selector": { "type": "uuids", "values": ["UUID 1", "UUID 2", "UUID 3"] },
        "tagPrefix": "proxy",
        "selectFrom": "ALL"
      },
      {
        "selector": { "type": "uuids", "values": ["UUID cdn"] },
        "tagPrefix": "cdn",
        "selectFrom": "ALL"
      }
    ]
  },
  "burstObservatory": {
    "pingConfig": { "timeout": "6s", "interval": "1m", "sampling": 3, "destination": "http://www.google.com/generate_204", "connectivity": "" },
    "subjectSelector": ["proxy", "cdn"]
  }
```

### Отключение маршрутизации в Happ [id=1017414, id=1017416]
- `happ://routing/off` (дока: https://www.happ.su/main/ru/dev-docs/routing)

### Получение логов ноды Remnawave [id=1070582]
```bash
docker exec -it remnanode xlogs
```

### Убрать стандартное меню бота (Rich Menu) [id=1059420, id=1060082, id=1079604]
Ставь rich menu переменные в бота; настройка: `Main Menu Rich Enabled` в настройках кабинета.

### Критичный абуз Bedolaga (тариф + скидка) [id=1036743]
Тариф с ненулевой сырой ценой + 100% скидка через period_discounts промо-группы → покупка/продление за 0 ₽, end_date растёт на полный период; через switch переносится на дорогой тариф.
