Cabinet v1.44.1: 100% скидка + race condition в Telegram Link Widget, sparkles в карточке триала [id=320023..320105]. Hotfix v3.45.1 [id=320771|Fisk].
- Панель 2.7.0+: у кого-то ноды отвалились/xray не стартует [id=319658|Max, id=317712|Voi]; у Alexy ноды не отвалились — обновил, ресетнул [id=317701]; порядок обновления по совету «фсбшника»: сначала панель, потом ноды везде, потом бот, потом веб-кабинка [id=317700|Andrey]; обновление панели до 2.7.4: триал не выдаёт сквад — решение: «В тарифе протыкай сервера» + «на тарифе подарочек ткни» [id=319048..319051]; совместимость: 2.7.4 панель + 2.7.0 нода = легло; 2.7.3 панель + 2.7.0 нода работает, но ошибки сыпит [id=321177, id=321179|Локо Aaaao].

- Перенос бота (правильный сценарий от Роман [id=318218]): «сделать дамп бд на том сервере откуда переносишь, запустить отдельно контейнер с бд бота и восстановить дамп, а потом запустить все остальное». - Перевыпуск подписки (блок устройства в подписке) [id=318822|Andrey|03.04 12:01]: панель → найти пользователя → действия → перевыпуск подписки → полный перевыпуск; потом в админке бота синхронизация с панелью; период сохранится, ссылка поменяется, старая ссылка перестаёт работать. Альтернатива: ревок ключей [id=318776|R0xTaDDy].
- Автопродление багов (Mr Lyagushka): пользователь может продлевать отключённый тариф по сниженной цене (58 вместо 89) — в `app/service/subscription_auto_purchase_service.py`, функция `_prepare_auto_extend_context` отсутствует проверка «активен ли тариф» [id=320730, id=321124, id=320843-логи]; автопродление пишет «Недостаточно средств» и всё равно продлевает [id=320843].
- Цены автопродления: на тарифах — цены из тарифов; в классик — из env/конфигураций/цен в боте [id=319539..319541|Egor].

- Обратный прокси кабины: если IP бота меняется после рестарта — скрипт R4z [id=317011|R4z]:
```
BOT_IP=$(docker inspect remnawave_bot | grep -A 1 "IPAddress" | grep -Eo '([0-9]{1,3}\.){3}[0-9]{1,3}' | head -1)
echo "Новый IP бота: $BOT_IP"
sudo sed -i "s|proxy_pass http://[0-9.]*:8080|proxy_pass http://$BOT_IP:8080|g" /etc/nginx/sites-available/cabinet
sudo nginx -t && sudo systemctl reload nginx
```
