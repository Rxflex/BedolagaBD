## Период 25.04–15.05.2026 — Bedolaga v3.49–3.55, Cabinet 1.49–1.52

- **Сравнение панелей** [id=450241/500243] (13.05): «Рассылка-подписки: сравнение с Марзбаном, 3x-ui — ремна лучше; Марзбан стабилизируется (скрипт GoTry), 3x-ui просто стартануть».
- **Готовая связка 3x-ui + Caddy + Reality (Self Steal) в Docker с автоматическими сертификатами через Caddy**: https://github.com/DeduskaPikhto/3x-ui-setup [id=439348] (02.05).
- Нужные подсети аезы в бане — из-за школьных гайдов на пикабу: «все бежали ставить 3x-ui с аезой» [id=443113].
- `Warp+ ($4.99/mo) не обязателен; в 3x-ui warp не нужен` [id=494034].
- **Требования панели (docs.rw/docs/install/requirements)** [id=455992]: 2 ГБ ОЗУ, но лучше 4 [id=456059]; «1 CPU + 2 RAM хватит точно» [id=456081]. По факту: 2 ГБ RAM для ремны мало [id=470237]; панель+бот на чистой квм съели 3.5 ГБ [id=470207]; чистая установка 1.10 ГБ [id=470213]; «на голую 2/2 хватит точно» [id=471502]; бот на 1 CPU / 2 RAM «не жалуюсь» [id=471789]; 2/4 тянет 1000, 4/8 — 2500 человек [id=459027, 459295]. Сервер Сервхост 1/1/10 не воркает для панели [id=464146]; для бедолаги хватит тарифа «2-й» (~5 EUR) [id=443008]; «бот 5 минут поднимался на калькуляторе» (про слабый хост) [id=427284]; «Не берите на панель 1/2 за 166₽» [id=406540]; ExpressHost 166₽ 1/2 — «пора повзрослеть» [id=406540].
- **Бот не на ноде**: «Можно ли разместить бота вместе с нодой?» — «можно, но не стоит» [id=457670, 457673]. Кабина и бот на одном сервере — «отдельный сервер лучше» [id=417705, 417917]. «Панель сабки на одном серваке — 40% впнов вижу с открытым IP-шником, панель и сабка на одном серваке» [id=425591, 425617].
- **Панель на ру-сервере**: «у меня ремна уже полгода на ру стоит», «панель на ру держу, проблем не наблюдаю» [id=427539, 428467, 425333]; «Панель Remnawave живёт на afk-нодах — не падает ни разу» [id=427178]. Для бота разница есть — телеграм в рф не работает [id=462048, 462062]; «Бот на ру-сервере не работает (телега заблокирована)» [id=430975]; урок ММТС-9: бот/саппорт и панель не держать в РФ-ДЦ [id=438159, 438264, 438270].
- **Панель на БС не ставят** — если БС-сервер заблокируют и бекапов нет, пропадает вся инфраструктура [id=443314–443316].
- **Не держать в РФ при падении API**: «Если сервер на beeget спб (ТСПУ), то с VPN всех надо ставить под мост» [id=413467].
- **Remnawave vs самопис**: «Кто-нибудь делал полную миграцию бедолаги, банхаммера, ремны и всего говна?» — «На новом сервере бекап подними и всё» [id=435400, 435405].
- **Хосты с лёгкой заменой IP под панель**: p2g, aurorex, kyonix [id=488926].
