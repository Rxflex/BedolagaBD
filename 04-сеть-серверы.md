## 1. Ядро и sysctl-тюнинг

### 1.1 BBR / congestion control
- Канон включения BBR:
```bash
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf && sysctl -p
```
[id=50126..50135|Дмитрий|02.11.2025], повтор [id=1066537|07.08.2026].
- BBR-скрипт Дмитрия: включает bbr2 при наличии, fq, `tcp_fastopen=3`, большие буферы, лог `/var/log/network-optimize.log` [id=50126..50135|02.11.2025].
- Теория: BBR даёт прирост при потерях/узких местах; при скорости Wi-Fi выше тарифа разницы нет [id=50754..50765|IS|03.11.2025].
- Вместимость нод с BBR (Ivan-стата, 16.12.2025): 1/2 → BBR1 15–25 / BBR3 20–35 активных; 2/4 → 40–60/60–90; 4/8 → ~100/120–180; 8/16 → 200–250/300–400. BBR3 требует изменения ядра [id=112903].
- Внимание: кастомное ядро BBR3 не имеет TC-модулей — шейпер на BBR3 не работает, откатывайте ядро [id=138513|Дмитрий|28.12.2025].
- BBR включать при перегрузе 500+ юзеров (дедик 2 CPU/128 GB уходит в 300% CPU) [id=408005|Frist|26.04.2026].
- Ядро XanMod с BBRv3/BBRv1 — установка с проверкой GPG и подбором сборки под CPU, без автоперезагрузки (в составе node-diagnostic) [id=923728|Илья|20.07.2026].
- Некоторые хостеры дают BBR/AES-NI включёнными: Beget (BBR вкл хостингом) [id=797199], VPSPay (BBR вкл, IPv6 off) [id=206904]; у других выключено — просить ТП [id=237101].

### 3.4 XDP
- XDP-фильтр на ноде: все порты кроме 443/22/1488 DROP; 443 — только RU ISP; 22 — только свой IP; 1488 (порт нода-панель) — только IP панели. Режим native лучший, generic лучше nftables/iptables; зависит от ядра и сетевухи. Для UDP — SYN cookies; против спуфинга source IP XDP особо не помог [id=991903|徹夜 高橋|29.07.2026].
- Массовая классификация ASN (AS1–AS216475, 4 млрд IP отсканировано): правило «из РФ ISP/MOB — ALLOW, остальное DROP»; для экспатов — обратная логика на отдельных нодах [id=992197|29.07.2026].
- На ноды анти-DDoS бесполезен — «достаточно панели (и кабинета) с анти-DDoS» [id=993786, 991903]; DROP не-РФ XDP бесполезен против залива/спуфа [id=1178614].
- Спуфинг: TCP SYN не требует своего IP в source; провайдер без BCP 38 позволяет подмену; сервер никогда не установит соединение со спуф-IP; XDP «все РФ ESTABLISH, остальное DROP» валится от спуфа [id=1025001, 1083206, 1025082]. Амплитудные атаки зарезаны провайдерами: NTP monlist, DNS ANY, SNMP, Chargen/QOTD/SSDP, Memcached — остались прямые SYN/ACK/RST спуфинг и UDP флуд [id=1096563|11.08.2026].
