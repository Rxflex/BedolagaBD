## Соглашения в тексте

- `[id=123456](https://t.me/c/2941121338/123456)` — пруф: номер сообщения в чате и ссылка на него (6642 штуки).
  В таблицах пайпы внутри метки экранированы (`id=123\|автор\|дата`). Часть ссылок трёхсоставные — с id форум-треда.
  Если нужен только номер — регексп `\[id=([^\]]+)\]` по-прежнему работает.
- `note_045` — ссылка на первоисточник `source/notes/note_045.md`.
- Даты — только `ДД.ММ.ГГГГ`. Период документа/раздела пишется в заголовке (`## Период 16.05–05.06.2026 …`).
- Конфиги и команды приводятся **дословно**; пометка «дословно» означает «скопировано из сообщения без правок».
- Устаревшее не удаляется, а датируется: в теме обхода блокировок любой рецепт живёт 1–3 месяца.
- Противоречия оставлены обеими версиями — если в ответе используется спорный факт, стоит упомянуть обе.

## Чего не делать

- Не изобретать факты и не «дополнять» из общих знаний: всё в базе привязано к пруфу. Нет пруфа — нет записи.
- Не подавать рецепты как актуальные без даты: рядом с методом всегда указывать, на какой момент он работал.
- Не править сгенерированные файлы (`MAP.md`, `indexes/*` кроме `термины.md`, `docs/*/README.md`, `assets/*`) — правки затрутся; менять источник и перегенерировать:

```bash
python _tools/build_nav.py && python _tools/build_indexes.py && python _tools/check_links.py
```

- Не добавлять новый документ мимо спеки: сначала запись в `SECTIONS` в `_tools/kb_lib.py` (файл, человеческое название, описание), потом сам файл, потом `build_nav.py`.

## Контекст темы (коротко, чтобы не гадать)

- **Remnawave** — панель, **Bedolaga** — Telegram-бот-магазин к ней, **Cabinet** — веб-ЛК. Ноды — серверы с Xray.
- Год прошёл под ТСПУ: Reality (основа 2025) к июню 2026 выбита, главный рабочий транспорт — **XHTTP + selfsni**, запас — **Hysteria2**, лечение шейпинга — **мост RU→EU**.
- Деньги — «серые» платёжки с комиссией 3–12 %; главная боль — вебхуки и двойные зачисления.
- Хостинг — расходник: подсети банят, аккаунты CDN сносят, серверы изымают; правило чата — не держать всё у одного провайдера.
