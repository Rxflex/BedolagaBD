# Правила общения

[⌂ База знаний](README.md) · [Как дополнять](CONTRIBUTING.md) · [Приватность](SECURITY.md)

Короткие правила для issue, PR и обсуждений. Задача одна: чтобы база оставалась полезной, а разбор фактов не превращался в перепалку.

## Можно и нужно

- Спорить с фактом: приводить пруф, дату, свой опыт. «У меня не работает» с деталями — полезно.
- Править чужие формулировки, если они неточны, и объяснять почему.
- Помечать устаревшее датой вместо удаления.

## Нельзя

- Оскорбления, травля, переход на личности, дискриминация по любому признаку.
- Публикация персональных данных участников: полные имена, телефоны, адреса, места работы, скриншоты личных переписок. См. [SECURITY.md](SECURITY.md).
- Реклама услуг без фактов опыта, спам, продажа доступов и мануалов в issue.
- Требования «удалите факт, потому что он мне невыгоден» без содержательного возражения. Требование об удалении **своих** данных — исключение, оно выполняется без обсуждения.

## Как решаются конфликты

1. Спор по факту решается пруфом: id сообщения, дата, кто говорил. Побеждает более проверяемая версия; при равных — в базе остаются обе с пометками даты.
2. Нарушение правил общения — предупреждение, затем блокировка в репозитории.
3. Решения принимает владелец репозитория. Обжалование — там же, в issue.

## Дисклеймер по содержанию

База описывает обход блокировок и VPN-инфраструктуру в контексте российского регулирования. Это архив опыта, а не призыв к действию и не юридическая консультация. Обсуждения «как нарушить закон» и запросы на помощь в противоправных действиях в issue не приветствуются.
