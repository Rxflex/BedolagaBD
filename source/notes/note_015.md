## Caddy: полный конфиг Remnawave + Bedolaga (миниап + вебхуки) [id=79181, 79182; Whiteness/YungCayde, 30.11]
Полный рабочий Caddyfile, автор Valerii Bezkorovainyi (foxlyvpn.xyz). Структура:
- Домен вебхуков `apibot.домен` с `encode gzip zstd` и handle-блоками на каждый платёжный вебхук, каждый проксируется на `remnawave_bot:8080` c `header_up Host {host}`, `header_up X-Real-IP {remote_host}` и `transport http { read_buffer 0 }`:
  `/yookassa-webhook`, `/platega-webhook`, `/cryptobot-webhook`, `/wata-webhook`, `/heleket-webhook`, `/tribute-webhook`, `/pal24-webhook`, `/mulenpay-webhook`
- В том же блоке `handle /app-config.json` c `header Access-Control-Allow-Origin "*"` (тоже на бота) и catch-all `handle` на бота.
- Миниап `miniapp.домен`: `encode gzip zstd`; `handle /miniapp/*` → бот; `handle /app-config.json` с CORS → бот; статика: `root * /var/www/remnawave-miniapp`, `try_files {path} /index.html`, `file_server`.
- Панель `remna.домен { reverse_proxy * http://remnawave:3000 }`
- Подписка `sub.домен { reverse_proxy http://remnawave-subscription-page:3010 { header_up X-Forwarded-Proto https; header_up X-Forwarded-Host {host} } }`
[id=6876-6888 (79681...), 6900-7030]

## YooKassa в .env (пример) + баг неавто-проверки платежа [id=80500, Genik; 78669-78678]
```
YOOKASSA_ENABLED=true
YOOKASSA_SHOP_ID=112****
YOOKASSA_SECRET_KEY=live_SSO5***************
YOOKASSA_RETURN_URL=https://***.ru/payment_success

```
Симптом: инвойс создаётся и оплачивается, но зачисление только после ручной «Проверить платеж» в админке — у ЮKassa, CryptoBot, Platega. Причина: вебхук платёжки не доходит до бота (реверс-прокси/секрет-ключ в env). Проверка хуков: `curl https://доменхуков/health/unified` — выводит список включённых способов оплаты [id=79200, 79203, hdhdh4226ru]. Браузером хуки отклоняются намеренно (безопасность) [id=79199].
- Обход ЮKassa-блока запросов с иностранных IP: бот на РФ-сервер; либо прокси-сервер в РФ с самописным микро-сервисом перед Yookassa API (эндпоинт менять в .env — просьба автору бота) [id=80769, 80775, SawGoD Fake]; либо через ТП ЮKassa (восстановили за пару часов) [id=80900].
- ЮKassa блокает вебхуки с зарубежных IP: у кого бот за рубежом РФ — не работает [id=80753, Илья Захаров].
- SNI-пустой запрос к СБП-qr ЮKassa лог (service: yookassa_service, создание платежа с Idempotence-Key) [id=80500].

## Анти-БС и внешний сквад [id=79638-79647]
Внешние сквады в Remnawave вешаются поверх уже заданных настроек и переопределяют значения из других разделов; с ботом не работают (бот не умеет внешние сквады); практически юзают как роутинг.
Обход БС рецепт (hdhdh4226ru, 01.12, id=80435): указать помимо доменов ТТ пару крупных сайтов, которые проверяют IP, и иностранные DNS 1.1.1.1 / 8.8.8.8; перенаправление доменов ТТ на иностранный серв помогает 50/50 [id=79160].
Обход БС на xhttp+reality с белыми списками (рассказ, 01.12, id=79775-79786): маршрут без роутинга Россия-Латвия, просто Латвия + SNI travel.yandex.ru, xhttp, reality; заработало у одного пользователя на МТС; до Латвии с БС; на Мегафоне белые списки не берутся, Билайн должен работать [id=79860-79869].
- Yandex Cloud: обход БС требует отдельной настройки; ip из пула, обходящего WL, нашёл один пользователь [id=80680].
