## Bedolaga: релиз v3.0.0 — «Новый веб-кабинет, суточные тарифы и умная докупка трафика» (16.01)
- **[id=173476|Egor|16.01]** Changelog (ключевые пункты дословно-близко):
  - **Новый веб-кабинет**: полностью переработанный интерфейс; отдельный репо `https://github.com/BEDOLAGA-DEV/bedolaga-cabinet` (автор @pedzeo); JWT-авторизация и настраиваемый CORS; `⚠️ Старая /miniapp/ будет удалена в ближайшие дни!`
  - **Суточный тариф**: новый тип тарифа с ежедневным списанием, идеален для пробного периода.
  - **Умная докупка трафика**: каждый пакет живёт свои 30 дней независимо; купил 50 ГБ сегодня — сбросится через 30 дней; купил ещё 50 через неделю — сбросится по своим 30 дням.
  - **Лимиты докупки**: макс. количество докупаемых устройств; макс. объём докупаемого трафика.
  - **Фиксы**: множественные баги тарифной системы; проблемы старого режима покупки.
  - **Новые переменные**:
```
CABINET_ENABLED=true
CABINET_JWT_SECRET=your_secret
CABINET_ALLOWED_ORIGINS=https://cabinet.yourdomain.com
```
  - Обновление: `cd /root/remnawave-bedolaga-telegram-bot && git pull origin main && make reload` / `make reload-follow` / через веб-админку bedolagam.ru.
  - Вебкабинет ставится РУКАМИ отдельно (в отдельном репо), не из докера бота [id=173589..173590, 173625..173627]. Обновление бота без установки кабинета — бот продолжает работать на старой миниапке [id=173592..173594].
- **[id=173486..173487, 173490..173491|16.01]** Рефать бедолагу не стали — «бедолага продолжает жить, поддерживаться и улучшаться», разрабов много; готовится полностью новый проект со всем багажом опыта. Рекомендация: с classic подписок перейти на тарифы.
- **[id=173493, 173515, 173519|16.01]** Кабинет сделал @pedzeo; прилы с Remna API — красота (@tsdev); Суба может добавить кабинет в автоустановщик.
