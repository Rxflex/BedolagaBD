## Anti-DDoS по классике и «эджи билайна» (дискуссия Deaddos vs рынок)
- **[id=966812|Deaddos]** Спор: «зачем юзать эджи, если сам домен билайна (cname) выдаёт вполне белые IP» — раскрывает контекст использования EDGE-IP у CDN; «эджи умирают иногда» — «это правда» [id=967014|myaso]. «У нас бывает раз в сутки отмирают» [id=967019|myaso].
- **[id=966982|myaso]** Определение (дословно, важно):
```
Эдж (edge) — нода/сервер, точка присутствия в сети CDN (PoP). По сути дедик или пул дедиков в одном PoP.
Anycast — тип адреса, который анонсируется с нескольких точек одновременно через BGP. Формально (RFC 4291/4786/7094) — адрес, назначенный нескольким интерфейсам/нодам; путь решает routing (обычно ближайший по BGP-метрикам хоп).
то, каким путём трафик до этого адреса доходит — это anycast-routing, а не сам anycast
эдж = нода
anycast = адрес раздачи (IP); к одному эджу может быть привязано сколько угодно anycast-адресов
```
- **[id=967317|—]** «Если так судить… то эджи умирают иногда» — «не я готов» (сравнение myaso vs Deaddos).
