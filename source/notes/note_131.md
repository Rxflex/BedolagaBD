## Bedolaga / Remnawave — фичи и фиксы
- Bedolaga обновление (Egor, [id=916051]): новый метод оплаты cisPay (пополнение картой/СБП, узел payments_cispay в дереве настроек админки, переводы на 4 языка; бэкенд отдаёт метод динамически, поэтому статистика/транзакции/Payment Health подхватывают автоматически через общий METHOD_LABELS); состав промокода чекбоксами (баланс + дни подписки + промогруппа комбинируются в одном коде — раньше тип промокода был взаимоисключающим); кнопка построения полной реферальной сети («Вся сеть» — режим взаимоисключающий с чипами, кэши полного и точечного графов разделены); кнопка «Отправить сообщение» в карточке пользователя; даты/числа форматируются по языку интерфейса (маппинг на BCP-47: ru-RU, en-US, zh-CN, fa-IR).
- Grace access (бот): выдаёт временный доступ (72ч по умолчанию) с сохранением лимитов тарифа [id=918647]; условие: если подписка завершена администратором — грейс не выдаётся [id=916448]. Воркер виден в логах: Grace reconciliation completed [id=916430]. Для теста: купить платную подписку и уменьшить время в ремне [id=916523].
- Рич-меню Bedolaga: рич не включается без логотипа — либо дефолтный, либо ждёт свой; если ссылка не картинка, бот выглядит как «не рич» [id=916532]; `MAIN_MENU_RICH_LOGO_URL=none` — пусто = авто-режим, а не «без» [id=916665]. Премиум-эмодзи (tg-emoji/img) в рич-сообщениях последний бот игнорирует, на тестовом боте работает — просят фикс [id=918666]. Ошибка рич-меню: RICH_MESSAGE_PHOTO_NO_MEDIA_FOUND / RICH_MESSAGE_PHOTO_URL_INVALID (у одного бота рич работает, у другого нет при том же лого) [id=916272, 919685].
- Кабинет Bedolaga: рандомная ошибка Invalid or expired Telegram authentication date; в логе initData rejected: too old age_hours=1487.8; вопрос про refresh tokens как решение без увеличения срока токена [id=919234, 919638, 919666].
- Триал Bedolaga выдаёт один из 4 сквадов — решение: закинуть все в один сквад [id=919169, 919203].
- Шаблоны Xray в Remnawave: Настройки > Шаблоны XRAY — добавить шаблон с конфигом и роутингом, подключить через панель [id=915262..915265].

```
  error_page 418 = @xhttp_poll_legacy;
  if ($arg_sid = "") { return 418; }
  rewrite ^/api/v4/media/session/poll$ /api/v4/media/session/poll/ break;
  proxy_pass http://127.0.0.1:10085;
}
```

## CDN: Beeline / Yandex / VK / Selectel / MWS — факты и опыт

Новая тарификация с 1 июля: по факту «ничего не поменялось», только стало считаться за запросы; аккаунты-пустышки с грантом (4к) раз в 2 месяца за ~500₽ достаточны, на 2-3 тб держатся [id=919120, 919123, 919129, 919135..919137, 919139, 918695..918696]. Пинг стабильный, в игры (Дота) поиграть можно, обрывов не замечено; «на билайне помню по кд всё падало» [id=918838..918852, 918831..918834].
- VK CDN: аккаунты 50-70$, гайды 40-70$, настройка 50-70$; по пингу «VK получше» [id=913484, 913487]; VK начал детектить VPN на части нод (правила direct/proxy по доменам помогли частично) [id=915252, 916369..916374, 919377..919381].
- Selectel CDN: на INCY не заводится (mux/x-cache), на Happ завелось [id=917443, 917454]; универеальны, 3 Гбит/с, часть подсетей до 10 Гбит/с; +5-10 мс пинг, в игры играбельно, обрывы кратковременные; доступ к госуслугам у них закрыт (анти-DDoS, чтобы не дудосили) [id=918830..918856, 917737..917757].
- MWS (VMware Cloud): зоны МСК/НСК/СПБ, подсети 176.109.92/24, 176.109.94/24, 176.109.85/24, 176.109.82/24, 176.109.88/24, 91.185.83/24; безлимит, 5 Gb/s; любое количество IP на аккаунт [id=913935, 916458]. Обмен MWS (176.109.85.0/24, 5 Gbit/s) на Timeweb [id=918686].
