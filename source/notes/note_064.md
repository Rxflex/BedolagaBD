## Nginx vs Caddy vs HAProxy
- Для простой работы (панель, бот, кабинет) — Caddy [id=347866,347883,349020,349052,349056].
- Для маркавки под сайт — nginx [id=349059,349061,349062].
- HAProxy: для сложных роутов на мосту, разбивка по sni или path, лучше nginx [id=351082,351084,351096,351104].
- Nginx proxy manager — под «элитных» с гб [id=347852].
- nginx - лучше для маскировки под сайт, caddy - по стандарту, haproxy - для сложных цепей [id=349059,349061,349062,351086,351104].
