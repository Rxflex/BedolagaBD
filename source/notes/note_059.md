## Решала v2.90 — multi-rule eBPF шейпер трафика (анонс)
- **[id=321673|Дмитрий|04.04.2026 03:24]** РЕШАЛА v2.90 — шейпер трафика нового поколения. Перед созданием нового конфига шейпера удалить старый.
  - Движок на базе eBPF + EDT (Earliest Departure Time) — работает в ядре Linux, без юзерспейса. Каждый IP-адрес получает независимый лимит; до 32 правил одновременно.
  - Режимы: Статика (жёсткий лимит всегда, напр. IP → ровно 5 МБ/с) и Динамика (Burst + Штраф: превысил квоту → 0.5 МБ/с на 60с; VoIP/мессенджеры не замечают).
  - Пример: правило #0 порт 443 статика 5 МБ/с; #1 порт 8443 динамика 3 МБ/с; #2 порт 2083 статика 10 МБ/с — одновременно на одном сервере.
  - Работает на уровне IP-пакетов (L3), не читает содержимое пакета — Reality/XHTTP/gRPC/WS/TLS не мешает.
  - vs tc+u32: старый способ имел коллизии IP при 256+ юзерах, один лимит на весь сервер; eBPF EDT — 0% коллизий, IPv6 из коробки, дробные скорости.
  - Настройка: меню reshala → [2] Шейпер трафика, wizard: номер правила 0..31, интерфейс, режим, порты (443 или 443,8443,2083), скорости (0.5/1.5/3 МБ/с...).
