## Кабинет: фикс VITE-переменных в готовом Docker-образе (не работает вход через ТГ)
- **[id=187135|art vs|21.01.2026]** Готовый образ (image: ghcr.io/bedolaga-dev/bedolaga-cabinet:latest) игнорирует VITE_... из .env — переменные запекаются только при build. Фикс — entrypoint с sed-инъекцией в docker-compose кабинета:
  ```yaml
  services:
    cabinet-frontend:
      image: ghcr.io/bedolaga-dev/bedolaga-cabinet:latest
      env_file:
        - .env
      entrypoint: >
        sh -c "sed -i 's/I=\"\",j=A/I=\"$VITE_TELEGRAM_BOT_USERNAME\",j=A/g' /usr/share/nginx/html/assets/index-*.js && nginx -g 'daemon off;'"
  ```
  В .env: `VITE_TELEGRAM_BOT_USERNAME=имя_бота` (без @). Пересоздать контейнер, перезапустить nginx/caddy, Ctrl+F5. Проверка:
  ```
  docker exec cabinet_frontend sh -c "grep -o '.\{0,20\}ИМЯБОТА.\{0,20\}' /usr/share/nginx/html/assets/index-*.js"
  ```
  (ответ `,I="ИМЯБОТА",j=A?A.name:"Cabine` = ок) **[id=187442|art vs]**
