Векторы: (1) продление при эффективной цене ≤ 0 всё равно добавляет период — нет проверки цены/лимита/идемпотентности; (2) Tariff.is_free смотрит на сырые period_prices, поэтому 100 коп. тариф не считается бесплатным, free-guard не срабатывает, проратация доплаты зануляется скидкой. Фиксы: отбивать покупку/продление при эффективной цене ≤ 0 (или один раз на явно бесплатном), учитывать цену после скидки в is_free и switch-guard, идемпотентность на повторные клики + кап на макс. срок подписки.
