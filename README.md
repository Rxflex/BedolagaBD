## Как проверять пруфы

`[id=NNN]` — id сообщения в экспорте. Открыть в `messages*.html`: файл = диапазон ~4000 id (например id 183033 → `messages2.html`). В заметках-источниках (`_extraction/notes/note_*.md`) тот же id лежит рядом с дословным текстом сообщения.

## Что НЕ вошло (намеренно)

Мемы, флуд, личные перепалки, реклама услуг без фактов опыта. Приоритет: конфиги/команды дословно → методики → даты/факты.
